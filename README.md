# Advanced-CSS

## Описание проекта

**Advanced-CSS** — небольшое веб-приложение с галереей изображений. На странице отображаются четыре фотографии, загружаемые с сервиса [Lorem Picsum](https://picsum.photos). Приложение демонстрирует использование современных возможностей CSS для размещения и оформления элементов.

## Возможности проекта

- Отображение четырёх изображений в галерее.
- Расположение изображений с помощью **Flexbox** и перенос на следующую строку при необходимости.
- Адаптивная ширина изображений: на экранах шириной менее 360 пикселей каждое изображение занимает 100% ширины контейнера.
- Кнопка **New images** для обновления страницы и загрузки изображений.
- Плавное изменение цвета кнопки при наведении курсора.

## Как запустить проект

### В CodeSandbox

1. Откройте проект в CodeSandbox.
2. Импортируйте репозиторий GitHub или откройте уже созданный sandbox.
3. Откройте файл index.html и запустите предпросмотр (Preview).
